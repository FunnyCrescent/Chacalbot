# MD — редактируемый контент бота

Здесь живут ВСЕ тексты, которые ты можешь править руками. Движок во время игры
читает НЕ эту папку, а замороженную копию сессии — так правки не прилетают
игрокам посреди активной кампании.

## Структура

| Путь | Что это |
|------|---------|
| `prompts/*.md` | Системные промпты LLM-агентов (master, ask, moder_ai, moder_ai_dispatch, renderer, npc_ai, db_bot, consolidator) |
| `characters/*.md` | Листы персонажей (сюда же бот складывает загруженные игроками файлы) |
| `settings/*.md` | Жанровые сеттинги; `registry.json` — служебный каталог сеттингов; `custom/` — созданные через бота |
| `ready.md` | Флаг коммита: `False` → `True` |
| `_applied/` | СЛУЖЕБНЫЙ кэш последнего подтверждённого состояния. Не редактировать. |

## Как применить правки

1. Отредактируй любой файл в `prompts/`, `characters/`, `settings/`.
2. Запиши в `MD/ready.md` слово `True` (одной строкой).
3. После полного завершения текущего раунда бот сам перенесёт правки
   во внутренний кэш и вернёт `ready.md` в `False`.
4. Правки увидят только НОВЫЕ сессии (созданные после коммита).
   Уже идущие сессии доигрывают со своей копией — это осознанное поведение.

## Плейсхолдеры в промптах

`{{EDITION_LABEL}}` и `{{EDITION_NOTE}}` подставляются автоматически при загрузке
(значение зависит от `DND_EDITION` в конфиге). Не удаляй их из текста.

## Переменные сессии

Каждая сессия при создании получает слепок `MD/_applied/` в
`data/sessions/<id>/MD/.../*_copy.md` — движок всю жизнь сессии читает только его.
При завершении/удалении сессии копия удаляется автоматически.
