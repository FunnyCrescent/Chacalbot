# Skill Checks & Ability Checks — D&D 5e (2014 PHB)

## Ability Checks

An **ability check** represents a character's attempt to accomplish something challenging. The DM sets the **Difficulty Class (DC)** — the target number for the check.

**Ability Check Formula**: d20 + Ability Modifier + Proficiency Bonus (if proficient) ≥ DC

### Standard Difficulty Classes
| DC  | Difficulty     |
|-----|----------------|
| 5   | Very Easy      |
| 10  | Easy           |
| 15  | Medium         |
| 20  | Hard           |
| 25  | Very Hard      |
| 30  | Nearly Impossible |

## Skills

Each skill is tied to a specific ability. Proficiency in a skill means you add your proficiency bonus to checks using that skill.

| Skill          | Ability | Skill          | Ability |
|----------------|---------|----------------|---------|
| Acrobatics     | DEX     | Animal Handling| WIS     |
| Arcana         | INT     | Athletics      | STR     |
| Deception      | CHA     | History        | INT     |
| Insight        | WIS     | Intimidation   | CHA     |
| Investigation  | INT     | Medicine       | WIS     |
| Nature         | INT     | Perception     | WIS     |
| Performance    | CHA     | Persuasion     | CHA     |
| Religion       | INT     | Sleight of Hand| DEX     |
| Stealth        | DEX     | Survival       | WIS     |

### Variant: Skills with Different Abilities
The DM may call for a skill check using a different ability than the default. Examples:
- **Strength (Intimidation)**: Flexing muscles to threaten.
- **Dexterity (Stealth)**: Standard, but **Charisma (Stealth)** for blending into a crowd.
- **Intelligence (Investigation)**: Standard, but **Wisdom (Investigation)** for searching a room by feel.

## Proficiency

- **Proficient**: Add proficiency bonus (+2 to +6 based on character level).
- **Expertise** (Rogue level 1, Bard level 3, and certain feats): Double the proficiency bonus for that skill. This is NOT doubling the total — only the proficiency portion.
- **Half-proficiency** (e.g., Jack of All Trades): Add half the proficiency bonus (rounded down) to ability checks you are NOT proficient in.
- **No proficiency**: Roll d20 + ability modifier only.

## Advantage and Disadvantage

**Advantage**: Roll two d20s and take the **higher** result.
**Disadvantage**: Roll two d20s and take the **lower** result.

### Sources of Advantage
- Attacking an unseen/unaware target.
- Target is blinded, paralyzed, restrained, or stunned (melee).
- Target is prone (melee within 5 ft).
- Help action (ally helps you).
- Guiding bolt, Bless, Bardic Inspiration (add to roll, not true advantage).
- Hiding successfully and then attacking.
- Racial features (e.g., Lucky halfling: re-roll 1s).

### Sources of Disadvantage
- Attacking while blinded, frightened, poisoned, or prone.
- Target is invisible (without seeing invisible).
- Ranged attack while within 5 ft of a hostile creature (unless Crossbow Expert).
- Ranged attack at long range.
- Medium or heavy armor without proficiency.
- Two-weapon fighting without light weapons.

### Stacking Rules
- **Multiple advantages** = still just advantage (they do NOT stack to "super advantage").
- **Multiple disadvantages** = still just disadvantage.
- **Advantage + Disadvantage = NEITHER** (they cancel out — roll a single d20, regardless of how many sources of each).
- This is the core design philosophy of 5e: avoid stacking modifiers.

## Passive Checks

A **passive check** is a special ability check that doesn't involve rolling dice. It represents average performance over time.

**Passive Check** = 10 + Ability Modifier + Proficiency Bonus (if proficient) + other modifiers

### Common Passive Checks
- **Passive Perception**: Most important passive check. Used to determine if a character notices something without actively searching. Default for noticing hidden creatures, traps, and ambushes.
- **Passive Investigation**: Noticing clues without actively investigating.
- **Passive Insight**: Detecting that an NPC is lying without actively trying to discern the truth.

### Passive Checks with Advantage/Disadvantage
- **Advantage**: +5 to passive check.
- **Disadvantage**: -5 to passive check.

## Group Checks

When a group attempts the same task, the DM can call for a **group ability check**:
- **All succeed individually**: Each character rolls separately.
- **Group check**: At least half the group must succeed for the group to succeed overall. Average the rolls or use the rule where the majority determines success.

**Example**: A group trying to sneak past guards — the group's Stealth check is compared against the guards' passive Perception. The noisiest member determines the group's result, or half the group must beat the passive Perception.

## Tool Proficiencies

Tools provide proficiency with specific equipment:
- **Thieves' Tools**: Disable traps, pick locks (DEX check + proficiency).
- **Herbalism Kit**: Create potions, identify plants (INT/WIS check + proficiency).
- **Disguise Kit**: Create disguises (CHA/INT check + proficiency).
- **Forgery Kit**: Create forgeries (DEX/INT check + proficiency).

Tool proficiency can combine with skill proficiency for **advantage** on specific tasks (e.g., proficiency in both History and Mason's Tools gives advantage on History checks related to stonework).

## Saving Throws

A **saving throw** (save) represents an attempt to resist a spell, trap, or hazard.

**Saving Throw** = d20 + Ability Modifier + Proficiency Bonus (if proficient in that save)

Each class is proficient in two saving throws:
| Class     | Proficient Saves      | Class     | Proficient Saves      |
|-----------|----------------------|-----------|----------------------|
| Barbarian | STR, CON             | Fighter   | STR, CON             |
| Bard      | DEX, CHA             | Monk      | STR, DEX             |
| Cleric    | WIS, CHA             | Paladin   | WIS, CHA             |
| Druid     | INT, WIS             | Ranger    | STR, DEX             |
| Rogue     | DEX, INT             | Sorcerer  | CON, CHA             |
| Warlock   | WIS, CHA             | Wizard    | INT, WIS             |

**Death Saves** are a special type of save (d20 with no modifiers) — see Combat Rules.
