# Character Creation Rules — D&D 5e (2014 PHB)

## Ability Scores

Six ability scores define a character: **Strength (STR), Dexterity (DEX), Constitution (CON), Intelligence (INT), Wisdom (WIS), Charisma (CHA)**.

### Generation Methods
1. **Standard Array**: 15, 14, 13, 12, 10, 8 — assign to abilities as desired.
2. **Point Buy**: Start at 8 in all scores. 27 points to distribute. Cost per score: 8=0, 9=1, 10=2, 11=3, 12=4, 13=5, 14=7, 15=9. No score can exceed 15 before racial bonuses.
3. **Roll 4d6 drop lowest**: Roll four six-sided dice, discard the lowest, sum the remaining three. Repeat six times and assign.

### Ability Modifiers
Modifier = (Score - 10) // 2 (integer division, rounding down).

| Score | Modifier | Score | Modifier |
|-------|----------|-------|----------|
| 1     | -5       | 10-11 | 0        |
| 2-3   | -4       | 12-13 | +1       |
| 4-5   | -3       | 14-15 | +2       |
| 6-7   | -2       | 16-17 | +3       |
| 8-9   | -1       | 18-19 | +4       |

### Applying Racial Bonuses
After generating base scores, add racial ability score increases. In the 2014 PHB, each race provides fixed bonuses (e.g., Elf: +2 DEX; High Elf: +1 INT). These are added ON TOP of the base scores.

## Racial Traits

Each race provides:
- **Ability Score Increases**: Fixed bonuses to specific abilities (2014 rules).
- **Speed**: Base walking speed in feet.
- **Size**: Small or Medium (affects weapon usage, carrying capacity, squeezing).
- **Languages**: Common + racial language(s).
- **Racial Features**: Darkvision, resistance to damage types, proficiencies, cantrips, special abilities.
- **Subraces**: Some races have subraces (e.g., Hill Dwarf vs. Mountain Dwarf) that add further bonuses and features.

Key racial restrictions:
- **Small** creatures have disadvantage on attack rolls with heavy weapons. Heavy weapons' two-handed property is unchanged.
- **Darkvision** does not stack. A creature with Darkvision from multiple sources still sees 60 ft (or the best range if different).

## Class Features

Each class provides at 1st level and beyond:
- **Hit Die**: Determines HP (e.g., d12 for Barbarian, d6 for Wizard). HP at 1st level = maximum hit die + CON modifier. HP at higher levels = hit die roll (or average) + CON modifier.
- **Proficiencies**: Armor, weapons, tools, saving throws, skills.
- **Features**: Class-specific abilities gained at specific levels (e.g., Fighting Style at 1st level for Fighter, Sneak Attack for Rogue).
- **Spellcasting**: Some classes are spellcasters (full, half, or third caster), with specific spellcasting rules.
- **Subclasses**: Chosen at a specific level (varies by class — 1st for Cleric/Sorcerer/Warlock, 2nd for Druid/Wizard, 3rd for most others). Subclass features replace or augment class features.

## Multiclassing

**Prerequisites**: Each class has ability score prerequisites (e.g., Fighter: STR 13 or DEX 13). You must meet the prerequisites for BOTH your current class and the new class.

**When you multiclass**:
- Gain hit points of the new class's hit die + CON mod (NOT the maximum at 1st level for additional classes — only your first class gets max hit die).
- Gain proficiencies of the new class (but NOT all — see Multiclass Proficiencies table in PHB p. 164).
- Do NOT gain the new class's starting equipment.
- Spellcasting: Combine levels per the Multiclass Spellcaster table. Known/prepared spells are tracked per-class separately.

**Experience Penalty**: None in 5e. You level up at the same XP thresholds regardless of how many classes you have.

**Class feature interaction**: Features from one class work with the other (e.g., a Fighter/Rogue can use Sneak Attack with Fighter weapons if they have finesse). However, Unarmored Defense does not stack — you choose which formula to use.

## Background

Every character selects a background, which provides:
- **Skill Proficiencies**: 2 skills (sometimes more).
- **Tool Proficiencies**: 0-2 tools/languages.
- **Feature**: A background feature (e.g., Noble's Position of Privilege, Soldier's Military Rank) that provides roleplaying benefits, not mechanical ones.
- **Suggested Characteristics**: Personality traits, ideals, bonds, flaws — these are roleplaying prompts, not mechanical constraints.
- **Starting Equipment**: Based on background + class.

**Custom Background**: Per PHB/SAC, you can mix any two skills + any two tools/languages + any feature + equipment equivalent to a listed background. The result must match the power level of existing backgrounds.

## Level Advancement

Characters gain levels by accumulating experience points (XP):
- **Milestones**: DM can use milestone leveling instead of XP.
- **XP thresholds**: See PHB advancement table. Example: Level 2 = 300 XP, Level 3 = 900 XP, Level 5 = 6,500 XP.
- **Maximum level**: 20 in standard 5e play.

At each level:
- Roll (or take average) hit die + CON modifier for new HP.
- Check for new class features, spell slots, proficiency bonus increases.
- At levels 4, 8, 12, 16, 19: Ability Score Improvement (ASI) or feat. Fighters and Rogues get additional ASIs.
